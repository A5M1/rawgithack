A fork of rawgit.hack.

This instance serves source files from GitHub, GitLab, Bitbucket, Gitea and Codeberg with correct Content-Type headers. Public file URLs and short links stay accessible without an account.

What is different from the original?

  • It runs on this domain, independently from the original rawgit.hack service.
  • It uses a Vercel/Express deployment with MongoDB instead of the original nginx-only setup.
  • Accounts and sessions are stored in MongoDB. The dashboard is login-protected.
  • Signed-in users can create short links, including custom names such as /s/my-file.js.
  • Registration is invite-only. Admins create one-time registration links from the dashboard.
  • The original proxy behaviour is preserved: development/production cache modes, legacy /owner/repo/ref/file paths, CDN paths and the HTML phishing notice.

This instance is not affiliated with rawgit.hack or any of the source-hosting services.
